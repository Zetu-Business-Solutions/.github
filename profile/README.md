## About

Zetu Business Solutions is a Kenya-based software company. We design, build, and operate web and mobile platforms for businesses, institutions, and startups, from first prototype to production deployment. We also run hands-on coding classes and developer mentorship.

<table>
  <tr>
    <td align="center" width="25%"><b>Full-stack</b><br/><sub>Frontend, backend, database, and infrastructure under one roof</sub></td>
    <td align="center" width="25%"><b>Multi-tenant</b><br/><sub>SaaS architecture with isolation, billing, and role-based access</sub></td>
    <td align="center" width="25%"><b>Payments-ready</b><br/><sub>M-Pesa, Paystack, and gateway integrations</sub></td>
    <td align="center" width="25%"><b>Production-grade</b><br/><sub>Security hardening, monitoring, and CI/CD from day one</sub></td>
  </tr>
</table>
